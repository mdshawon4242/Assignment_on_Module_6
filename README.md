# Assignment on Module 6 - JavaScript & OOP

এই repository তে Module 6 এর সবগুলো Assignment রাখা হয়েছে।  
এখানে JavaScript এর Array Methods, Object Methods, Set, Map, Spread & Rest, Class & Constructor, এবং OOP concepts নিয়ে কাজ করা হয়েছে।

## Tasks

### Task 1: Array Methods
- `push()` দিয়ে নতুন item যোগ করা
- `pop()` দিয়ে শেষ item remove করা
- `forEach()` দিয়ে সব item console এ দেখানো

### Task 2: map() & filter()
- `map()` দিয়ে প্রতিটি number এর সাথে 10 যোগ করা
- `filter()` দিয়ে 30 এর বেশি number বের করা

### Task 3: reduce(), find(), findIndex()
- `reduce()` দিয়ে মোট marks বের করা
- `find()` দিয়ে প্রথম 70 বা তার বেশি mark খুঁজে বের করা
- `findIndex()` দিয়ে 85 এর index বের করা

### Task 4: Object Methods
- `Object.keys()` দিয়ে keys দেখানো
- `Object.values()` দিয়ে values দেখানো
- `Object.entries()` দিয়ে key & value দেখানো
- `hasOwnProperty()` দিয়ে property আছে কিনা check করা

### Task 5: Set
- `add()` দিয়ে নতুন value যোগ করা
- `delete()` দিয়ে value remove করা
- `has()` দিয়ে value আছে কিনা check করা
- `forEach()` দিয়ে সব value print করা

### Task 6: Map
- `set()` দিয়ে data যোগ করা
- `get()` দিয়ে data নেওয়া
- `has()` দিয়ে property আছে কিনা check করা
- `size` দিয়ে data count করা

### Task 7: Spread & Rest
- Spread দিয়ে দুটি Array একত্র করা
- Rest দিয়ে function এ যতগুলো number দেওয়া হবে সবগুলো যোগ করা

### Task 8: Class & Constructor
- `Student` নামে একটি Class তৈরি করা
- Constructor এ থাকবে: `name`, `age`, `course`
- দুইটি student object তৈরি করা

### Task 9: Inheritance & Overriding
- `Person` নামে parent class
- `Student` নামে child class
- `introduce()` method override করে আলাদা output দেখানো

### Task 10: Small OOP Project ⭐
- `BankAccount` class তৈরি করা
- Property: `name`, `balance`
- Method: `deposit()`, `withdraw()`
- শেষে account holder এর নাম ও current balance console এ দেখানো
- Bonus: static method ব্যবহার করার চেষ্টা
